# Security policy

## Reporting a concern

If you find a security or privacy concern in this public portfolio, email
`sppierce34@yahoo.com` with the affected page or file and enough detail to
reproduce the issue. Please do not include real athlete, customer, payment, or
credential data in a report.

## Repository boundary

This repository contains public portfolio code and high-level engineering
documentation. The production source repositories for the featured
applications are private and are not in scope for public disclosure here.

Do not commit credentials, environment values, access tokens, private records,
internal addresses, tunnel identifiers, database connection strings, or
proprietary source copied from the production applications.
